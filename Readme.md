# i.MX DDoS Blocker for OrangeBox2.0

A DDoS blocker system bases on machine learning for the i.MX943 OrangeBox2.0 board. This repository contains the LUCID-CNN model training, quantization, conversion, and deployment pipeline.

## Features
- **Machine Learning Model**: LUCID-CNN neural network for DDoS detection
- **XDP based packet inspection**: eBPF-based packet filtering for high-performance threat mitigation
